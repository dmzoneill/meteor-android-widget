# Meteor Android Widget

<p align="center">
  <img src=".github/logo.png" alt="meteor-android-widget logo" width="128" />
</p>

An Android home screen widget for customers of Meteor, the Irish mobile
network. It shows account usage such as remaining credit, minutes and
texts.

## What it does

- Logs in to the My Meteor site and reads the account balance and
  usage.
- Shows the figures on a home screen widget, refreshed on a timer.
- Lets you change settings and themes, and can show notifications.

## Tech

- Java for Android (minimum SDK 10)
- Eclipse project files and Ant-style `default.properties`

## Building

Import the project into Eclipse with the Android Developer Tools, or
build it with the Android SDK. A prebuilt `bin/MeteorWidget.apk` is
included.
